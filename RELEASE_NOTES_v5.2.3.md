# FretSense 5.2.3

## Highlights

- Android and Windows source in one public-ready repository
- Multi-instrument modes: Guitar, Keyboard, Ukulele, Violin
- Original chord → transpose → manual capo flow
- Timeline / Play Now / Practice synchronized with active transpose/capo state
- Active chord diagram synchronized with transposed chord
- Capo-friendly playable shape shown separately from sounding chord
- Premium dark/bronze icon and UI
- Local song library
- Tuner, metronome, scales, loop/practice and strumming tools
- Local/optional AI guitar isolation

## Windows

- New native desktop shell based on pywebview + Edge WebView2
- Stable localhost origin to preserve IndexedDB/library data
- Browser fallback for microphone permission compatibility
- One-click install/run scripts
- PyInstaller build script
- GitHub Actions Windows build and tagged release workflow
