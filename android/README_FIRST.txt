FretSense Multi-Instrument Android v5.2.0 — FULL PROJECT

OPEN IN ANDROID STUDIO
1. Extract the ZIP.
2. Android Studio -> Open.
3. Select the top-level folder: FretSense_Multi_Instrument_Android_v5_2
4. Wait for Gradle Sync.
5. Connect your Android phone with USB debugging enabled.
6. Select the phone and press Run.

CAPO FLOW
After a song is analyzed, FretSense first shows the original detected chords.
Example original song:
E · G#m · C#m · B

Capo initially: No Capo

If YOU select Capo Fret 4, FretSense keeps the original chords visible and shows:
Play shapes:
C · Em · Am · G

The app does not automatically pick a capo or transpose the analyzed song.

TRANSPOSE
The Transpose screen is ordered as:
1. Original Song Chords
2. Choose Capo Fret
3. Shapes To Play
4. OPTIONAL Change Song Key (- / +)

Leave optional key change at 0 to keep the original song key.

MULTI-INSTRUMENT
Guitar, Keyboard, Ukulele and Violin modes remain included.
Capo controls are used only for instruments that support capo mode.

BUILD APK
Build -> Build App Bundle(s) / APK(s) -> Build APK(s)
