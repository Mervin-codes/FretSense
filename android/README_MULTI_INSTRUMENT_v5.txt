FretSense Multi-Instrument v5

New Instrument Mode:
- Guitar — standard E A D G B E, chord diagrams, capo, 6-string melody tab
- Keyboard — chord tones, note+octave melody timeline, keyboard scale view
- Ukulele — G C E A chord shapes, capo, 4-string melody tab
- Violin — G D A E melody position guide, scale fingerboard, bow-rhythm guide

How it works:
Analyze a song once, then open Instrument and switch modes. The song analysis stays loaded; only the playing representation changes.

Important:
The current neural isolation model is still specifically guitar-focused. Instrument Mode changes theory/practice/tab views; it does not claim instrument-specific stem isolation for keyboard, ukulele or violin.
